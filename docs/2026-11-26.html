Granular.Build

기존 AI 개발 도구는 브라우저 탭이 번잡하거나 터미널 중심이어서 비개발자가 쓰기 어렵고, 에이전트 간 메모리가 공유되지 않는 한계가 있었습니다. Granular는 디자이너인 창업자가 본인의 프로젝트 제작 과정을 개선하려고 직접 만든 도구입니다. 파일과 AI 에이전트, 프로젝트 메모리를 하나의 시각적 공간에 통합해 기획부터 출시까지 한곳에서 마칠 수 있도록 설계했습니다. 웹사이트 제작부터 홍보 영상까지 Granular 자체를 활용해 완성했습니다.

가격 · 무료+유료

Clam AI

이메일 업무를 자동화하려는 사용자가 자신의 이메일 계정(Gmail)을 연동해 AI 에이전트의 접근 권한을 안전하게 제어하는 데이터 보안 관리 서비스입니다. 일상 언어로 "여행 이메일만 읽고 답장 초안만 쓰기" 같은 규칙을 설정해 두면, AI가 해당 권한 범위 내에서만 안전하게 작업합니다.

주요 기능

  • 자연어 기반 이메일 접근 규칙 설정
  • AI 승인 대기 및 사전 승인 요청
  • 모든 AI 작업 기록 및 차단 로그

만든 사람의 소개

AI 에이전트에 이메일 수신함처럼 민감한 데이터의 접근 권한을 통째로 맡기는 일은 보안상 위험합니다. Clam은 에이전트에 무제한 권한을 주는 대신, 사용자가 명확한 자연어 규칙으로 행동 범위를 제어하는 보안 레이어를 제공합니다. 이메일 본문을 직접 저장하지 않으며 승인이 필요한 작업은 메신저로 사람에게 확인받아 이메일 권한 남용을 방지합니다. 이메일을 시작으로 향후 MCP 권한 관리 레이어로 영역을 넓혀갈 계획입니다.

  • 피싱 메일을 정상 이메일로 분류할 위험 우려
  • 규칙 변경 후 적용 결과 확인의 불투명성

주요 기능

가격 · 유료
