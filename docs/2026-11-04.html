Cedric AI for Meetings

창업자나 영업 담당자가 화상 회의 프로그램(Zoom, Meet, Teams)에 자신 대신 참석시킬 수 있는 AI 에이전트입니다. 사전 지침과 연동 데이터를 바탕으로 슬라이드를 넘기며 발표하고 참석자 질문에 답하며 회의 후 필요한 작업까지 처리해 줍니다.

주요 기능

  • 화상회의 슬라이드 발표
  • 실시간 질의응답 대응
  • 회의 후속 조치 자동 실행

Agent Inbox

개발자가 만든 AI 프로그램(에이전트)에 전용 이메일 주소나 슬랙(Slack), 텔레그램(Telegram) 계정을 생성해 주는 서비스입니다. 사람이 평소 사용하는 메신저나 메일함에서 AI에게 메시지를 보내면 AI가 그 대화방 안에서 바로 대답하거나 작업 승인을 요청할 수 있습니다.

주요 기능

  • 단일 API 기반 전용 수신함 생성
  • 슬랙/텔레그램 대화 동기화
  • 메신저 내 승인/거절 처리

가격 · 무료

만든 사람의 소개

AI 에이전트가 업무는 잘 처리하지만 사람과 소통하려면 메신저마다 연동 코드를 짜야 하는 번거로움을 없애고자 만들었습니다. 하나의 API만 연결하면 에이전트에 이메일과 메신저 계정이 만들어져 사용자가 어디서든 메시지를 보내고 답장을 받을 수 있습니다. 2분 만에 연동 설정이 끝나는 오픈소스 프로젝트입니다.

Hyperresearch

연구자나 서비스 개발자가 궁금한 분야를 입력하면 다양한 웹 데이터와 논문을 조사해 근거가 명시된 보고서를 작성해 주는 서비스입니다. 거짓 정보를 지어내는 환각 현상 대신 정확한 원문 출처를 함께 제시하거나, 정보를 찾지 못한 경우 명확히 '찾을 수 없음(not found)'이라고 알려줍니다.

주요 기능

  • 원문 대조 인용 검증 보고서
  • 검색 가능한 출처 데이터 금고
  • 지어내기 방지(not found) API

가격 · 무료

만든 사람의 소개

한 곳의 데이터 제공업체만 의존할 때 생기는 사각지대를 없애고자 40개 이상의 데이터 출처를 하나로 모아 만들었습니다. 조사가 끝난 뒤 수집된 데이터가 사라지지 않도록 원본 출처를 보관하고 언제든 찾아볼 수 있는 '출처 금고'를 제공합니다. 지어낸 답변 대신 검증된 원문 인용과 '찾을 수 없음'을 정확히 돌려주어 높은 신뢰도를 보장합니다.
