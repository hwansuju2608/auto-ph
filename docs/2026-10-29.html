TheySaid 4.0

제품 디자이너나 개발자가 작성 중인 기획안이나 화면을 Claude나 Jira 등의 작업 도구와 연결하여 사용하는 서비스입니다. 실제 사용자나 실제 고객 데이터를 학습한 가상 사용자가 이를 직접 이용해 보고 문제점을 즉시 찾아내 줍니다.

주요 기능

  • 가상 사용자 UX 테스트
  • 기획 도구 연동 자동 검증
  • AI 전용 보조 도구

만든 사람의 소개

기존에는 개발 및 디자인 변경 사항을 고객에게 확인받으려면 모집과 일정 조율에 시간이 오래 걸려 이 과정을 건너뛰는 경우가 많았습니다. TheySaid 4.0은 Claude, Replit, Jira 등 작업 중인 도구 안에서 가상 사용자나 실제 사람이 제품을 직접 써보게 하여 빠른 검증을 돕습니다. 10만 시간 이상의 사용성 세션 데이터와 실제 고객 데이터를 결합해 진짜 사람처럼 행동하는 합성 사용자를 제공하는 것이 차별점입니다. 티켓 디자인이 완료되면 자동으로 테스트가 실행되어 검증을 잊을 리가 없습니다.

Overmind

AI 에이전트(자동화 프로그램)를 만드는 개발팀이 실제 서비스에서 발생하는 실행 기록 데이터를 연결해 사용하는 플랫폼입니다. 복잡한 AI 인프라 구축 없이도 수집된 이용 데이터를 바탕으로 맞춤형 소형 AI 모델을 자동으로 학습시키고 성능을 평가해 줍니다.

주요 기능

  • 실행 데이터 추적 및 수집
  • 맞춤형 AI 모델 파인튜닝
  • 자동화된 성능 평가

만든 사람의 소개

대부분의 AI 제품이 몇몇 거대 모델에 의존하지만, 저자는 모든 팀이 자체 데이터로 학습 및 평가 루프를 직접 실행할 수 있기를 바라며 Overmind를 만들었습니다. Cursor나 Claude 등에 명령어 한 줄을 붙여넣으면 실행 데이터 추적부터 평가 세트 생성, 모델 학습 및 배포까지 단일 플랫폼에서 진행됩니다. 거대 AI 연구소나 GPU 예산 없이도 누구나 자신의 데이터에 최적화된 맞춤형 소형 AI 모델을 소유할 수 있습니다.

Orbit

스마트폰 중독과 무의미한 숏폼 시청을 줄이고 싶은 사람이 스마트폰에 설치해 사용하는 앱입니다. 지정한 시간 동안 특정 앱이 자동으로 잠기며, 잠금을 푸시려면 카메라 앞에서 스쿼트를 하거나 소액 결제를 하는 등 물리적·금전적 과제를 수행하게 만듭니다.

주요 기능

  • 일정별 자동 앱 잠금
  • 스쿼트·숨참기 등 해제 미션
  • 소액 결제 기반 잠금 해제

가격 · 유료

만든 사람의 소개

개발자 자신이 매일 10시간 이상 스마트폰을 사용하며 숏폼에 빠져드는 문제를 해결하기 위해, 손쉽게 우회 가능한 기존 차단 앱과 달리 차단을 푸는 과정 자체에 실질적 비용을 부과하도록 만들었습니다. 일정을 설정하면 앱이 차단되며, 스쿼트, 친구 승인, $0.99부터 시작하는 결제 등의 과제를 통과해야만 앱이 열립니다. 한 달간의 테스트를 통해 스마트폰 사용 시간을 10시간에서 6시간대로 대폭 줄이는 효과를 확인했습니다.

웹 개발자가 컴퓨터에서 개발 중인 웹사이트 화면을 열고 포인터로 클릭하여 사용하는 개발 도구입니다. 화면에서 어긋난 버튼이나 텍스트 요소를 클릭하고 말로 지시하면 AI 코딩 에이전트가 해당 코드 파일을 자동으로 찾아 코드를 수정해 줍니다.

주요 기능

  • 화면 요소 클릭 기반 버그 지정
  • AI 코드 자동 수정 및 실시간 미리보기
  • 웹 브라우저 내 코드 변경분 승인

가격 · 무료+유료

만든 사람의 소개

AI 코딩 에이전트를 쓸 때 "두 번째 카드의 아래 버튼"처럼 화면의 시각적 오류를 글자로 길게 설명하고 개발자 도구에서 코드를 복사하는 번거로움을 줄이고자 만들었습니다. 웹 화면에서 문제가 되는 요소를 클릭하고 지시사항을 입력하면 해당 요소의 스타일 및 소스 위치 정보를 AI에 자동으로 전달합니다. 변경된 코드 결과물은 웹 브라우저에서 먼저 확인하고 승인할 때까지 실제 파일에 적용되지 않습니다.

주요 기능

  • 8.5인치 OLED 디스플레이

가격 · 유료

NuPlay

기업의 고객센터나 운영팀이 기존 데이터베이스(Salesforce, SAP 등) 및 상담 채널을 연결해 사용하는 AI 플랫폼입니다. 음성 전화, 채팅, 이메일 문의에 AI 에이전트가 응대하며, 매번 상담이 끝날 때마다 데이터 기반으로 성능을 스스로 분석하고 개선합니다.

주요 기능

  • 옴니채널 AI 에이전트 응대
  • 기업 전산 시스템 연동
  • 실행 후 자동 분석 및 AI 자가 개선

만든 사람의 소개

대부분의 기업 AI 프로젝트가 배포 후 규정이나 제품 변화를 따라가지 못하고 정체되는 문제를 해결하고자 만들었습니다. 배포 후에도 매 실행 결과를 평가하고 스스로 성능을 개선하는 통합 플랫폼입니다. NuPro로 에이전트를 만들고, NuStack으로 기업 시스템을 연결하며, NuContext로 통합 지식을 구성하고, NuLoop를 통해 오류 진단 및 프롬프트 수정을 자동화합니다.
