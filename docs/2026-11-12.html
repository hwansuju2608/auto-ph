Alsona

영업 담당자나 기업이 자사 웹사이트와 추적할 구매 의도 신호를 설정하면, AI가 채용·투자·기술 변화 등 32가지 신호를 감시하여 타깃 기업을 찾아냅니다. 이를 바탕으로 AI가 맞춤형 이메일과 링크드인 메시지를 작성·발송하여 미팅까지 대신 예약합니다.

주요 기능

  • 32가지 이상 구매 신호 추적
  • 이상적 고객 점수화 및 사유 제공
  • 맞춤형 아웃리치 및 미팅 자동 예약

만든 사람의 소개

링크드인 자동화 플랫폼을 만들었던 개발자가 영업 아웃리치의 핵심이 적절한 타이밍과 필요성에 있다는 점을 깨닫고 Alsona를 개발했습니다. 웹사이트 주소만 입력하면 30초 만에 이상적 고객 프로필을 생성하고 32가지 이상의 신호를 감시하여 적절한 기업을 발굴합니다. 단순히 잠재 고객 목록만 제공하는 데 그치지 않고, 연락해야 하는 명확한 이유와 근거를 함께 제시합니다. 사용자의 말투와 어조를 학습한 AI 에이전트가 직접 메시지를 작성하고 발송하여 미팅 예약까지 진행합니다.

Seldon

소프트웨어 개발자나 품질 관리(QA) 팀이 웹 앱과 검증하고자 하는 목표를 일상 언어로 입력하면, AI 에이전트가 실제 사용자처럼 앱을 다각도로 조작하며 버그를 탐지합니다. 문제 발생 시 재현 과정과 화면 녹화 영상을 제공해 버그를 빠르게 해결하도록 돕습니다.

주요 기능

  • 자연어 기반 QA 테스트 생성
  • 실제 사용자 행동 경로 탐색
  • 버그 발생 시 녹화 영상 및 재현 단계 제공

가격 · 첫 10회 실행 무료

Latch.ai

회계 담당자가 화면을 열고 평소 하던 마감 작업을 말로 설명하면서 시연하면, AI가 화면·클릭·음성을 학습해 자동화 도우미를 만듭니다. 만들어진 도우미는 기존 시스템에서 반복 작업을 대신 수행하며, 예외 상황이 발생할 때만 담당자에게 확인을 요청합니다.

주요 기능

  • 음성·화면·클릭 3중 시연 기록
  • 프롬프트 작성 없는 자동화 도우미 생성
  • 예외 상황 발생 시 작업 일시정지 및 사람 확인 요청

가격 · 무료 플랜 제공 (신용카드 불필요)

Opal Reader

아이폰, 아이패드, 듀얼 스크린 기기(iPhone Duo)에서 PDF나 DRM 프리 EPUB 전자책을 읽으며 화면 옆에 메모를 작성할 수 있는 앱입니다. 하이라이트와 밑줄은 물론 손글씨나 텍스트 노트를 남긴 뒤 주석이 포함된 파일로 내보낼 수 있습니다.

주요 기능

  • PDF 및 DRM 프리 EPUB 읽기 지원
  • 페이지 옆 실시간 노트 작성
  • 주석 및 하이라이트 내보내기

가격 · 기본 읽기 무료 (문서 3개까지 주석 무료), Pro 버전 일회성 $14.99 USD
