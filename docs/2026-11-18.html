Zoom Slides

회의가 잦은 직장인이나 발표 자료를 자주 만드는 사용자가 Zoom 회의 기록이나 문서를 넣으면, AI가 발표 슬라이드와 발표자 노트를 자동으로 작성합니다. 회의 도중 별도로 화면을 공유하지 않고도 참가자들에게 슬라이드를 직접 전달해 함께 편집할 수 있습니다.

주요 기능

  • 회의 녹취록 기반 슬라이드 생성
  • Zoom 내 슬라이드 직접 공유 및 발표
  • 파워포인트 파일 내보내기 지원

만든 사람의 소개

Zoom 디자이너 팀이 디테일과 사용자 경험에 공을 들여 개발한 AI 프레젠테이션 도구입니다. 기존 AI 슬라이드 도구들이 수정하기 까다로운 HTML 형태에 그쳤던 점을 보완해, 처음부터 자유롭게 편집 가능한 슬라이드를 제공합니다. 회의에서 나눈 논의와 맥락이 빠짐없이 발표 자료로 이어지도록 만들었습니다. 화면 공유 대신 슬라이드를 직접 공유해 참가자들이 자유롭게 훑어볼 수 있다는 것이 큰 장점입니다.

Boost.space AgentOS

주요 기능

  • 1,500개 이상 업무 도구 연동
  • AI 에이전트 역할 및 권한 관리
  • 슬랙·팀즈 등 협업 툴 대화 지원

만든 사람의 소개

기업 데이터의 통합과 보안을 바탕으로 AI 에이전트가 실질적인 성과를 내도록 돕는 에이전트 전용 운영체제입니다. 기존에 쓰던 ChatGPT나 Claude 같은 AI 모델과 도구를 그대로 연동할 수 있습니다. 슬랙이나 팀즈 등 익숙한 업무 환경에서 에이전트에게 역할을 부여하고, 중앙 데이터 레이어로 문맥을 학습시킵니다. 다양한 AI 모델과 외부 도구를 연동해 자원을 효율적으로 활용하도록 돕습니다.

readywhen

이메일 업무가 많은 사용자가 비서 이메일 주소로 후속 연락이나 미답변건 추적을 요청하면, AI가 후속 메일 초안을 잡아줍니다. 사용자가 내용을 확인하고 답장으로 승인해야만 이메일이 발송되므로, 잊기 쉬운 후속 업무를 안전하게 처리합니다.

주요 기능

  • 이메일 팔로업 초안 자동 작성
  • 사용자 답장 승인 후 메일 발송
  • 미답변 상태 추적 및 리마인드

만든 사람의 소개

고객이나 투자자, 협력사와의 이메일 후속 연락을 챙기느라 지친 사용자를 위해 만든 이메일 전용 개인 비서입니다. 별도 앱 설치나 가입 절차 없이 지정된 이메일 주소로 할 일을 보내면 즉시 작동합니다. 사용자가 승인(send 답장)하기 전에는 절대 메일이 나가지 않도록 설계해 안전성을 높였습니다. 1,000개 이상의 기존 업무 도구와 연동되어 놓치기 쉬운 후속 작업을 알아서 챙깁니다.

사람들 반응 · 댓글 25개

새 앱이나 대시보드에 적응할 필요 없이 익숙한 이메일 화면을 그대로 쓰면서, 사용자 승인 기반으로 작동하는 방식이 좋은 평가를 받고 있습니다.

  • 별도 앱 설치 없는 이메일 인터페이스

  • 상대방의 모호한 답장에 대한 추적 기준 모호

한국 시장

수신함 내에서 전적으로 동작하며 승인 답장을 통해 이메일 팔로업 및 미답변건을 자동 추적해 주는 한국형 이메일 AI 비서는 드뭅니다.

OpenBot

개발자나 기업 보안 관리자가 자사 인프라에 직접 설치(자체 호스팅)해 기업 보안 기준에 맞는 AI 에이전트 작업 공간을 구축할 수 있습니다. 에이전트별 접근 권한과 비용을 관리하고, 이메일 발송처럼 중요한 작업은 사람의 사전 승인을 거치도록 설정합니다.

주요 기능

  • 자체 인프라 호스팅 지원
  • 에이전트 권한 및 승인 제어
  • 활동 감사 기록 및 비용 관리

만든 사람의 소개

AI 에이전트가 기업 시스템에 접근할 때 생길 수 있는 보안 및 책임 문제를 해결하려고 만든 모듈형 오픈소스 작업 공간입니다. 단일 인증(SSO)과 권한 관리 기능으로 에이전트가 접근하고 실행할 수 있는 영역을 엄격하게 제한합니다. 이메일 발송 같은 특정 작업은 사람의 승인을 받아야만 실행되며, 모든 활동 내역을 기록으로 남깁니다. 기존 개발 스택과 모델을 자유롭게 가져와 맞춤 제작하거나 자체 브랜드로 바꿔 쓸 수 있습니다.

사람들 반응 · 댓글 79개

외부 인프라 의존이나 서비스 장애 걱정 없이 자사 서버에서 원하는 모델로 AI 에이전트를 안전하게 운용할 수 있어 좋은 평가를 받습니다.

  • 자체 호스팅을 통한 완전한 데이터 소유

Appxiom

앱 및 웹 개발자가 자사 서비스에 연결하면 운영 중 발생한 튕김, 멈춤 등 버그와 가입·결제 단계의 이탈 데이터를 수집해 줍니다. 이렇게 확보한 운영 현장 데이터를 코딩 AI 에이전트(MCP 연동)에 전달해, AI가 버그 원인을 정확히 파악하고 코드를 수정하도록 돕습니다.

주요 기능

  • 운영 환경 앱 버그 감지
  • 목표 이탈 영향도(GFI) 분석
  • 코딩 에이전트용 MCP 연동

만든 사람의 소개

코딩 AI 에이전트가 소스 코드는 읽을 수 있지만 실제 서비스 환경에서 일어나는 오류를 알지 못해 대략적인 짐작으로 수정하는 문제를 해결하고자 개발했습니다. 회원가입이나 결제 같은 핵심 목표가 버그로 얼마나 차질을 빚었는지 영향도(GFI)를 측정해 에이전트에 전달합니다. 에이전트가 버그 수정을 진행하기 전에 현장의 맥락을 명확히 파악하도록 돕는 역할입니다. iOS, Android, Web 등 주요 프레임워크용 SDK와 MCP 커넥터를 기본 제공합니다.

사람들 반응 · 댓글 29개

단순한 오류 기록(스택 트레이스) 제공을 넘어, 버그가 결제나 가입 이탈에 미친 영향을 분석해 AI 에이전트에 전달하는 방식이 훌륭하다는 평가를 받습니다.

  • 버그와 비즈니스 목표 이탈의 연동 분석
  • AI가 코드 수정에 집중하도록 맥락 제공
  • 간단한 2단계 SDK 설치
  • 사용자 개인정보(PII)의 LLM 유출 우려
  • 버그 발생 직전의 사용자 작동 단계 파악 필요

한국 시장
