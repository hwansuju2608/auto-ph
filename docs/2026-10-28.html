주요 기능

  • 웹 기반 AI 에이전트 생성

개발자가 Mac 메뉴바에 켜두면, 코딩용 AI 에이전트 중 어떤 프로그램이 CPU를 과하게 사용해 기기를 뜨겁게 만드는지 실시간으로 알려주는 서비스입니다. 클릭 한 번으로 높은 부하를 주는 작업을 효율 코어(E-core)로 옮겨, 프로세스를 종료하지 않고도 기기 열을 식혀줍니다.

주요 기능

  • AI 에이전트별 CPU 점유 모니터링
  • 원클릭 효율 코어 작업 이전
  • 에이전트 세션별 과열 타임라인 제공

가격 · 유료 ($5 일시불)

만든 사람의 소개

개발자들이 AI 코딩 에이전트(Claude Code, Cursor 등)를 여러 개 띄워 놓으면 Mac이 과열되곤 하는데, 기존 활성 상태 보기(Activity Monitor)로는 어떤 에이전트가 원인인지 찾기 어려웠습니다. 이를 해결하고자 에이전트별 프로세스를 하나로 묶어 온도를 모니터링하고 과열 원인을 한눈에 파악하도록 만들었습니다. 작업을 강제로 종료하는 대신 효율 코어로 전환해 작업은 유지하면서 온도를 낮추며, 최근 업데이트로 일일 온도 기록과 타임라인 기능도 추가했습니다.
