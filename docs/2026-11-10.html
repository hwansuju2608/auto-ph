Product Hunt MCP

새로운 소프트웨어를 찾는 사용자가 AI 도구(클로드, 챗GPT 등)에 연동하면, 프로덕트 헌트(신제품 소개 플랫폼)의 제품 검색과 커뮤니티 리뷰 조회를 대화창에서 바로 처리해 줍니다. 또한 개발자가 소스코드 설명 문서(README)나 웹사이트 주소를 연결하면 신제품 등록용 초안을 작성하고 빠진 항목을 분석해 줍니다.

주요 기능

  • AI 기반 제품 검색 및 비교
  • 커뮤니티 리뷰 및 평점 조회
  • 제품 출시 등록 초안 작성

만든 사람의 소개

AI 도구에 어떤 서비스를 쓸지 질문하는 사용자들을 위해, 프로덕트 헌트의 실제 커뮤니티 평가 데이터로 제품 조사를 돕고자 만들었습니다. 과장된 마케팅 문구 대신 실제 사용자 반응과 제작자 정보를 바탕으로 대안 제품을 비교하고 추천받을 수 있습니다. 아울러 직접 만든 제품의 설명 문서와 웹사이트를 바탕으로 등록용 초안을 작성하고 부족한 점도 보완해 줍니다.

AXL

AI 제품 창업자가 웹사이트, 이메일, 고객 관리 시스템(CRM)을 연결하면, AI가 잠재고객 확보부터 판매, 온보딩까지 마케팅과 영업 작업을 자동으로 수행해 줍니다. AI 도구와 표준 연동 규격(MCP)으로 연결되어, 간단한 명령만으로 랜딩페이지를 만들거나 이메일 발송, AI 전화 응대 등을 실행할 수 있습니다.

주요 기능

  • 올인원 영업·마케팅 자동화
  • AI 모델 기반 고객 점수 측정
  • 자연어 명령으로 마케팅 실행

가격 · 무료 플랜 제공 (신용카드 등록 없이 월 연락처 500개, 이메일 5,000건, 메시지 5,000건 무료)

만든 사람의 소개

제품 개발보다 마케팅 도구 연동과 인력 채용에 비용이 더 많이 드는 문제를 해결하기 위해 올인원 플랫폼으로 만들었습니다. 여러 서비스를 복잡하게 연결하지 않아도 하나의 시스템에서 고객 행동 이력을 통합 관리합니다. AI 도구에 명령만 내려도 1,200개가 넘는 영업·마케팅 작업을 자동 처리하며, 100만 건의 거래 데이터로 학습한 AI가 고객의 구매 가능성을 예측해 줍니다.

주요 기능

  • 대화 내 구조화 데이터 추출
  • 원본 텍스트 위치 출처 연결
  • 실시간 대화 판단 및 분류

만든 사람의 소개

개발자가 자연어 대화에서 정형 데이터를 손쉽게 추출하고 실시간으로 의사를 결정할 수 있도록 만들었습니다. 추출한 데이터가 원본 문장의 어느 부분에서 나왔는지 출처를 명확하게 짚어 줍니다. 대화 전체를 다시 전송하지 않아도 대화 흐름에 맞춰 실시간으로 판단 결과를 업데이트합니다.

주요 기능

  • 웹사이트 기반 답변 봇 자동 생성

NoMac

iOS 앱 개발자가 AI 코딩 도구(Claude Code, Cursor 등)를 연동하면, 약 30초 만에 클라우드 Mac 환경을 준비하여 앱 빌드부터 시뮬레이터 실행, 앱스토어 제출까지 자동으로 처리해 줍니다. 작업이 끝나면 Mac이 곧바로 종료되므로 사용한 분(分) 단위로만 비용이 발생합니다.

주요 기능

  • 클라우드 맥 환경 30초 내 생성
  • 아이폰 시뮬레이터 실시간 화면 확인
  • 앱스토어 및 테스트플라이트 자동 제출

가격 · 시간당 $0.90 분당 과금 (유효기간 없는 $10 선불 충전 방식, 월 구독료 없음)
