MyClaw 3.0

AI 팀으로 여러 업무를 자동화하려는 사용자가 웹이나 슬랙, 메신저를 연결하면 원하는 역할을 맡은 AI 에이전트를 클라우드에 배치해 줍니다. 24시간 돌아가는 AI 에이전트들이 서로 정보를 공유하며, 사용자가 접속을 마쳐도 알아서 디자인이나 글 작성 등 지정된 업무를 계속 처리합니다.

주요 기능

  • 50개 이상 AI 모델 지원
  • 에이전트 간 공유 메모리
  • 클라우드 기반 상시 작업 수행

동료에게 업무 지시서를 주듯 간편하게 AI 팀을 짜도록 MyClaw 3.0을 개발했습니다. 리서치 담당이나 콘텐츠 작성자 같은 역할을 맡기고 필요한 도구와 파일을 연결해 두면, 자리를 비워도 클라우드에서 알아서 작업을 진행합니다. 예를 들어 디자인 담당 AI가 만든 포스터를 참조해 콘텐츠 담당 AI가 출시 이메일 문구를 쓰는 식으로 서로 협업합니다. 사용자는 나중에 돌아와 완성된 결과물만 검토하면 됩니다.

Airbot

업무 알림에 시달리는 창업자나 영업 담당자가 이메일, 슬랙(Slack), 캘린더, 고객관리 시스템을 연결하면, AI가 중요한 일을 선별해 메신저로 먼저 연락을 줍니다. 이메일 답장 초안 작성이나 회의 준비, 고객 데이터 업데이트를 미리 마쳐두므로 사용자는 메신저 창에서 승인 버튼만 누르면 됩니다.

주요 기능

  • 선제적 메신저 알림 발송
  • 이메일 초안 및 일정 자동 준비
  • 메신저 내 원클릭 업무 승인

가격 · 무료로 시작

만든 사람의 소개

하루 100개가 넘는 알림 때문에 정작 중요한 일에 집중하지 못하는 문제를 해결하려고 Airbot을 만들었습니다. 새로운 앱을 익힐 필요 없이 왓츠앱이나 아이메시지 같은 메신저에서 바로 이용할 수 있습니다. 이메일과 캘린더, 고객관리 도구를 연결해 두면 밤사이 데이터를 분석해 아침마다 필요한 업무 요약과 답장 초안을 보내줍니다. 단순한 보고에 그치지 않고 준비된 작업을 바로 승인할 수 있으며, 쓸수록 사용자의 작성 스타일과 업무 방식을 스스로 학습합니다.

  • 메신저 기반의 먼저 연락하는 방식

Hiring Right Now

구직자가 자신의 링크드인(LinkedIn) 프로필 주소를 입력하면 경력에 맞는 성장 스타트업을 자동으로 찾아줍니다. 해당 스타트업 창업자의 이메일 주소는 물론, 사용자의 경험을 담은 제안 이메일 초안까지 2분 만에 완성해 줍니다.

주요 기능

  • 링크드인 경력 기반 스타트업 매칭
  • 창업자 직통 이메일 제공
  • 맞춤형 아웃리치 이메일 생성

가격 · 무료 (회원가입 및 카드 등록 불필요), 90일 플랜 50% 할인 혜택 제공

만든 사람의 소개

수백 군데 지원서를 내도 답을 받지 못했던 구직 경험에서 출발해 지원자와 스타트업 간의 매칭 문제를 해결하고자 개발한 도구입니다. 구직자의 경력을 실제로 필요로 하는 스타트업을 찾아주는 데 집중했습니다. 프로필 링크만 입력하면 회원가입 없이 알맞은 스타트업 10곳과 창업자 연락처, 이메일 초안을 뽑아줍니다. 승인한 이메일은 사용자의 지메일(Gmail) 계정에서 직접 발송되므로 답장도 내 메일함으로 바로 들어옵니다.

QA.tech MCP

개발자가 개발 프로그램(IDE) 안에서 이 서비스를 연결하면, 품질 관리(QA) 에이전트가 실제 브라우저 화면을 직접 클릭하며 정상 작동 여부를 검증합니다. 코딩 AI가 만든 코드의 결함을 찾아 리포트로 전달하므로 개발자가 일일이 화면을 점검하지 않고도 코드를 고칠 수 있습니다.

주요 기능

  • 실제 브라우저 기반 E2E 자동 테스트
  • IDE 내 버그 감지 및 자동 수정 연동
  • 단일 프롬프트 기반 앱 구조 자동 분석

가격 · 50 추가 크레딧 제공 (약 1개월 분량, 프로모션 코드 PHMCP 입력 시)

만든 사람의 소개

코딩 AI 에이전트가 작업을 마쳤다는데 막상 앱을 켜보면 회원가입조차 안 되어 결국 개발자가 수동 테스트를 해야 하는 문제를 풀고자 만들었습니다. QA.tech MCP를 활용하면 개발 환경 안에서 실제 브라우저를 띄워 서비스 동작을 자동 탐색·검증할 수 있습니다. 프롬프트 한 줄로 웹 앱 구조를 파악하고 테스트를 시작합니다. 문제 발생 시 깨진 원인과 위치를 코딩 에이전트에 전달해 자동으로 수정하도록 처리합니다.

사람들 반응 · 댓글 24개

E2E 스크립트 작성 부담을 줄이고 코드 제출 전 테스트를 자동화해 준다는 평가가 높습니다. 다만 테스트 데이터 정리나 오류 수정 동작에 대한 우려도 있습니다.

  • 개발 환경(IDE)을 벗어나지 않는 자동 테스트

Canva MCP

디자인이나 마케팅 작업을 자동화하려는 사용자가 AI 에이전트/개발 도구를 캔바(Canva)에 연결하면, 텍스트와 레이어를 자유롭게 수정할 수 있는 디자인 파일을 알아서 생성해 줍니다. 배경 제거나 이미지 크기 조정 같은 편집 작업도 프롬프트 명령만으로 자동화해 브랜드 스타일의 다양한 홍보물을 쉽게 제작하도록 돕습니다.

주요 기능

  • 수정 가능한 디자인·이미지·영상 생성
  • 배경 제거 및 매직 레이어 자동 편집
  • 다양한 채널용 규격 자동 리사이즈

만든 사람의 소개

캔바의 강력한 디자인 기능을 외부 AI 에이전트나 개발 도구에 바로 이식할 수 있도록 플랫폼을 개방했습니다. 이제 AI 에이전트가 텍스트 수정이 가능한 캔바 디자인 파일, 이미지, 비디오를 직접 만들고 편집할 수 있습니다. 배경 제거, 매직 레이어, 자동 리사이즈 등 캔바의 핵심 기능을 개발자 API와 MCP로 제공합니다. 캔바는 단순한 디자인 도구를 넘어 AI 생태계를 위한 크리에이티브 인프라로 진화하는 중입니다.
